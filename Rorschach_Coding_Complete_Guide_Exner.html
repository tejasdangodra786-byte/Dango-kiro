1 INTRODUCTION

1.1 Purpose of Coding in Rorschach

Coding (also called "scoring") is the process of translating a subject's verbal responses to the Rorschach inkblots into a standardized set of symbols. These symbols represent the perceptual, cognitive, and affective operations that were involved in forming each response.

As stated in the Exner manual: "Every interpreter should always be aware that it is impossible to overemphasize the importance of accurate coding of the responses, compiling the sequence of scores correctly, recording frequency data precisely, and accurately calculating the numerous ratios, percentages, and derived variables."

1.2 Role of Coding in Exner's System

In the Comprehensive System, coding serves as the bridge between raw verbal responses and the Structural Summary. The Structural Summary — which contains all frequencies, ratios, percentages, and indices — is derived entirely from the coding decisions made for each response.

The system produces three interrelated data sets:

  1. Verbiage — the exact words used by the person
  2. Sequence of Scores — the order and coding of responses
  3. Structural Summary — the statistical plot of all coded variables (frequencies, ratios, percentages, indices)

1.3 Importance of Accuracy and Standardization

Even a SINGLE coding error can have a "domino effect" leading to multiple errors in interpretive hypotheses. For example, failing to code FT (Form-Texture) when present in the Popular response to Card VI could yield T=0 in the structural data, which would generate entirely wrong interpretive conclusions about interpersonal relations, es values, Adjusted D scores, and multiple indices.

The manual explicitly states two types of scoring errors:

  • Errors of Omission — forgetting to include a determinant in a blend, neglecting to code a pair, forgetting a Popular, or neglecting secondary contents. (More common in experienced scorers.)
  • Errors of Commission — neglecting the step-down principle and coding C instead of CF, scoring C' instead of Y when intent is unclear, selecting the wrong Z score, coding Vista when the answer is really FD, or selecting the wrong special score. (More common in less experienced scorers.)
Always review ALL coding before proceeding to interpretation. This is not necessarily to challenge the scoring but to ensure that omission or commission errors have not occurred.

2 PRE-CODING REQUIREMENTS

2.1 Verbatim Recording of Responses

The Exner manual states unequivocally: "Examiners should never fail to make a verbatim record of the verbalizations of the subject."

  • Record EVERY word the subject says — do not paraphrase or summarize
  • Use standard abbreviations only (e.g., "S" for subject, "E" for examiner, "Rpts" for repeats, "resp" for response)
  • Note non-verbal behaviors (pointing, tracing, turning card) in brackets
  • Record response time and card position if possible
There is NO excuse for failing to record verbatim. Without exact words, you cannot accurately determine determinants (especially the crucial distinction between shading types), special scores (which depend on exact wording), or content nuances.

2.2 The Inquiry Phase — Why It Is Critical for Coding

The Inquiry phase is where the examiner clarifies three things essential for coding:

  1. Location — WHERE on the blot was the response seen?
  2. Determinants — WHAT features of the blot made it look like that? (form, color, shading, movement)
  3. Content Clarification — WHAT exactly did the person see? (to determine content codes and form quality)

Key Inquiry Technique: The examiner repeats the subject's response and asks "What made it look like that?" or "I'm not sure I see it the way you do. Help me." The goal is to get the subject to articulate the perceptual features without leading them.

NEVER ask leading questions in inquiry (e.g., "Was it the color?" or "Did the shape remind you?"). Leading questions contaminate the response and make accurate coding impossible. The inquiry must be NON-DIRECTIVE.

2.3 Location Clarification

The examiner must be clear about exactly WHICH area of the blot was used. This requires:

  • Use of a location sheet (a reduced copy of the blot on which the subject outlines or points to the area used)
  • Subject's verbal description of the location ("the whole thing," "just the top part," "this little thing over here")
  • Comparing the subject's location to the D and Dd tables in the manual

2.4 Determinant Probing

In the Inquiry phase, the examiner seeks to identify what perceptual features (determinants) contributed to the formation of the response:

  • Form — "What made it look like [object]?" (shape/contour)
  • Color — Listen for color references; if color is used on chromatic cards, note whether it was mentioned spontaneously
  • Shading/Texture — Listen for references to "light," "dark," "fuzzy," "soft," "shadowy"
  • Movement — Listen for action words, postures, tensions
If the subject says something is "dark" or "shaded" and the intent is NOT clear, the Exner system has a specific rule: code diffuse shading (Y) rather than achromatic color (C'). This is the "step-down principle" — when in doubt between C' and Y, code Y.

2.5 Common Recording Errors to Avoid

  • Paraphrasing instead of verbatim recording
  • Not recording inquiry responses fully
  • Missing non-verbal cues (card rotations, pointing)
  • Adding interpretive notes that contaminate the raw data
  • Failing to clarify ambiguous responses during inquiry
  • Recording only the "interesting" responses and abbreviating others

3 OVERVIEW OF CODING VARIABLES

Every Rorschach response is coded across seven categories. These are always assigned in a specific sequence:

#CategoryWhat It CapturesExample Codes

2Developmental Quality (DQ)HOW well-organized is the percept?+, o, v/+, v
3Determinant(s)WHAT blot features made it look like that?F, M, FM, m, FC, CF, C, FT, TF, T, FV, VF, V, FY, YF, Y, FD, Fr, rF
4Form Quality (FQ)HOW WELL does the response fit the blot area?+, o, u, -

Standard Coding Sequence:
Location — DQ — Determinant(s) — Form Quality — (Pair) — Content — Popular — Special Scores
Every single response MUST be coded for ALL seven categories. If a category does not apply, it is simply omitted from the code string (e.g., no Special Score, no Popular). But Location, DQ, at least one Determinant, Form Quality, and at least one Content must ALWAYS be assigned.

4 STEP-BY-STEP CODING PROCEDURE

This is the main section of the guide. Each step below corresponds to one coding category, presented in the order in which coding decisions should be made.

STEP 1: LOCATION CODING

Location coding identifies which part of the inkblot the subject used to form their response. There are four main location codes:

A. Whole Response (W)

Definition: The subject uses the entire blot (all of the inkblot area) to form the response.

  • The ENTIRE blot area must be incorporated — nothing left out
  • If even a small area is excluded, it is NOT a W
  • White space included WITH the whole blot = WS (W with Space)

Example: Card V — "A bat" (using the whole blot) = W

If the subject says "the whole thing" but clearly describes only a portion during inquiry, code it as D or Dd based on what was actually used, NOT what they claim to have used.

B. Common Detail (D)

Definition: The subject uses a commonly identified area of the blot — an area that is frequently selected by most people taking the test.

  • D areas are listed in the Exner manual tables for each card
  • These are areas that at least 5% of the population use
  • Each card has numbered D areas (D1, D2, D3, etc.)
  • The specific D number should be recorded on the location sheet

Example: Card III — "Two people" (using the common dark lateral figures) = D

C. Unusual Detail (Dd)

Definition: The subject uses an infrequently identified area of the blot — an area that is NOT commonly selected (used by fewer than 5% of people).

  • Dd areas are also numbered in the manual tables (Dd21, Dd22, etc.)
  • Any area not classified as W or D is automatically Dd
  • Includes very small areas, unusual cuts, or edge details
  • If the subject uses an area that is NOT in the manual tables at all, it is still coded Dd

Example: Card I — "A tiny face" (using only a very small top center area) = Dd

D. Space Response (S)

Definition: The subject incorporates white space (the area between or within the inkblot) as a meaningful part of their response.

  • S is ALWAYS coded in addition to W, D, or Dd — it is a modifier
  • If white space is used WITH the whole blot: WS
  • If white space is used WITH a common detail: DS
  • If white space alone is used (rare): DS or DdS depending on the specific space area
Space (S) is NEVER coded alone — it is always combined with W, D, or Dd. The S indicates that white space was incorporated as a meaningful feature of the percept, not merely that the response happens to be near white space.

E. Ambiguity Handling for Location

SituationRule
Subject says "the whole thing" but describes only partCode based on what was ACTUALLY used (verify in inquiry)
Subject uses almost all of blot but omits a tiny areaIf the omitted area is very small and trivial, code W; otherwise code D or Dd
Subject combines two D areasIf the combination is common (listed as D), code D; if not, code W or Dd depending on total area used
Subject uses white space as figure and ink as groundCode with S modifier (figure-ground reversal)
Always refer to the location tables in the Exner manual for each card. The tables specify exactly which areas are D (common) and which are Dd (unusual). Do NOT guess — verify against the tables.
STEP 2: DEVELOPMENTAL QUALITY (DQ)

Developmental Quality reflects how well the response is organized or integrated — essentially, how sophisticated the perceptual-cognitive processing was.

A. Synthesized Response (DQ+) — Symbol: +

Definition: The response involves the meaningful integration of two or more discrete areas of the blot into a single, coherent percept. The areas must be related to each other in a meaningful way.

  • Two or more objects are seen AND they are in a specific, meaningful relationship to each other
  • OR a single object is described with clearly differentiated parts that are specifically related
  • The KEY criterion: there must be ACTIVE INTEGRATION — the parts must relate to each other

Examples:

  • "Two people lifting a pot" (Card III) — Two separate areas integrated into a relational scene = DQ+
  • "A butterfly sitting on a flower" — Two objects in meaningful spatial relationship = DQ+
  • "A woman in a long dress with a hat on her head" — Single object with specifically differentiated, related parts = DQ+
The essential question for DQ+ is: "Are two or more discrete blot areas (or discrete parts of an object) meaningfully related in the percept?" If YES = DQ+.

B. Ordinary Response (DQo) — Symbol: o

Definition: The response identifies a discrete, specific object with a natural outline or form demand, BUT without synthesizing multiple areas into a relationship.

  • The object has a specific shape (not vague or amorphous)
  • Only one object is seen OR multiple objects are seen but NOT in a meaningful relationship
  • Most common DQ level in records

Examples:

  • "A bat" (Card V, whole) — Specific form demand, single object, no synthesis = DQo
  • "A butterfly" (Card I, whole) — Specific form, no integration of separate parts = DQo
  • "Two people" (Card III) — Even though two objects are mentioned, if they are NOT described in a meaningful interaction = DQo

C. Vague/Synthesized Response (DQv/+) — Symbol: v/+

Definition: A synthesized response where at least one of the integrated components is formless or vague.

  • Two or more areas are integrated into a relationship (like DQ+)
  • BUT at least one component has no specific form demand (is vague/amorphous)

Example:

  • "Clouds surrounding a mountain" — Integration exists (spatial relationship), but "clouds" has no specific form demand = DQv/+

D. Vague Response (DQv) — Symbol: v

Definition: The response identifies an object or impression that has no specific form demand — it is amorphous, diffuse, or could look like anything.

  • Objects with no definite shape: clouds, smoke, fog, blood (without specific shape), darkness, shadow, paint
  • No integration with other areas
  • The object could be any shape and still be called that

Examples:

  • "Smoke" = DQv
  • "Blood" (without specific shape) = DQv
  • "Just darkness" = DQv
  • "Paint splattered" = DQv
"Blood" can be DQo if the subject describes it with a specific shape (e.g., "a drop of blood" — drops have specific shapes). But "blood splattered everywhere" = DQv because no form demand exists.

STEP 3: DETERMINANTS (MOST IMPORTANT SECTION)

Determinants are the features of the blot that contributed to forming the response. This is the most complex and critical coding category. A response may have ONE determinant (single) or MULTIPLE determinants (blend, separated by periods).

THE GOLDEN RULE: A determinant is coded ONLY if the subject provides evidence during either the Response Phase or the Inquiry that the blot feature contributed to forming the response. Do NOT assume determinants — they must be ARTICULATED by the subject.

A. FORM (F)

Pure Form — Symbol: F

Definition: The response is based SOLELY on the shape or outline of the blot area. No other blot feature (color, shading, perceived movement) contributed to the response.

  • Code F when the ONLY feature used is the contour/shape of the area
  • F is the most "basic" and "economical" determinant
  • It reflects the tactic of dealing with stimuli on a simple, economical level
  • If ANY other feature (color, shading, movement) contributed, do NOT code pure F — code the other determinant(s) instead

Examples:

  • "A bat — because of the shape, the wings spread out" = F
  • "A map — it's shaped like Africa" = F
F means ONLY shape was used. The moment any other feature is involved, it is no longer pure F. Even if form is ALSO used (e.g., "it's red and shaped like a butterfly"), the code becomes FC (Form-Color), not F.

Lambda (L) — Related Concept

Lambda represents the proportion of Pure F responses in a record:

Lambda = Number of Pure F responses / (R - Number of Pure F responses)

A Lambda greater than 0.99 suggests an avoidant style (simplifying complexity). This is relevant when interpreting but important for coders to understand why accurate F coding matters.

B. MOVEMENT DETERMINANTS

Movement determinants are coded when the subject perceives or attributes motion, action, or tension to the percept. The movement is NOT actually in the blot — it is projected by the subject.

Movement is NEVER actually in the blot (it's a still image). Movement is ALWAYS attributed/projected by the subject. This makes it a particularly important determinant for understanding cognitive operations.

B1. Human Movement (M)

Definition: A human (or human-like creature) is perceived as engaging in a kinesthetic activity — an action that requires the use of muscles or joints.

Code M When:Do NOT Code M When:
A human is performing an action (running, dancing, bending, lifting, fighting)A human is merely described as "standing there" without postural tension (this is debatable — see note below)
A human-like creature (angel, witch, elf, cartoon character) performs an actionAn animal performs an animal-like action (use FM instead)
A human figure is described in a tense posture that implies muscular effortAn inanimate object is moving (use m instead)
An animal performs a clearly HUMAN-like action (talking, cooking, arguing)The subject merely identifies a person without movement
Key Distinction: If an animal is doing something that ONLY humans do (e.g., two bears arguing, a rabbit cooking), it gets coded M (because the activity is human-like). If an animal is doing something animals naturally do (e.g., a bird flying, a dog running), it gets coded FM.

Active vs. Passive M:

  • Ma (active) — The figure is performing an action: "two people fighting," "a woman dancing"
  • Mp (passive) — The figure is in a passive posture: "a person sleeping," "someone kneeling in prayer," "two people looking at each other"

B2. Animal Movement (FM)

Definition: An animal is perceived as engaging in an action that is natural or typical for that animal species.

  • "A bird flying" = FM
  • "Two dogs fighting" = FM
  • "A frog jumping" = FM
  • "A spider crawling" = FM
If an animal is doing something ONLY humans do, code M not FM. "Two bears playing chess" = M (bears don't play chess in nature). "Two bears wrestling" = FM (bears naturally wrestle).

B3. Inanimate Movement (m)

Definition: An inanimate object or a natural force is perceived as being in motion or dynamic tension.

  • "A rocket blasting off" = m
  • "An explosion" = m
  • "Smoke rising" = m
  • "Blood dripping" = m
  • "Water falling" = m
  • "A leaf falling" = m (the leaf is not acting by its own volition)
The M vs FM vs m Decision:
- Is the moving thing HUMAN or doing something ONLY humans do? → M
- Is the moving thing an ANIMAL doing something natural for animals? → FM
- Is the moving thing INANIMATE (object, force of nature) or is motion occurring WITHOUT volition? → m

Active vs. Passive Superscript for All Movement

All movement determinants (M, FM, m) are further classified as active (a) or passive (p):

  • Active (a) — involves effort, exertion, dynamic action: running, fighting, exploding, flying upward
  • Passive (p) — involves rest, repose, static posture, drifting: sleeping, lying down, floating gently, hanging

C. COLOR DETERMINANTS

Color determinants are coded when the chromatic (colored) features of the blot contributed to forming the response.

CHROMATIC vs. ACHROMATIC: Chromatic color refers to the actual colors (red, orange, green, blue, pink, etc.) on Cards II, III, VIII, IX, X. Achromatic color refers to the black, grey, and white features (Cards I, IV, V, VI, VII and the dark areas on other cards). These are coded DIFFERENTLY.

C1. Chromatic Color (The Form-Color Hierarchy)

When chromatic color is used, the relationship between FORM and COLOR determines the specific code. This is the "step-down" principle:

CodeSymbolDefinitionForm DominanceExample
Form-ColorFCForm is PRIMARY, color is secondary. The object has a definite shape, and color adds to it.Form > Color"A red butterfly" (shape defines it, color enhances it)
Color-FormCFColor is PRIMARY, form is secondary. The color drives the response, but some vague form exists.Color > Form"A paint splatter, it's all colorful" (color drives it, vague shape)
Pure ColorCColor is the ONLY determinant. No form whatsoever. The object could be any shape.No Form"Blood" (on a red area — no shape required, just the redness)
THE STEP-DOWN PRINCIPLE (Critical Rule): If there is ANY doubt about whether to code FC or CF, always "step down" to the LESS form-dominated code. This means: when in doubt between FC and CF, code CF. This is because the system requires clear evidence of form dominance before coding FC.

How to Decide FC vs CF vs C:

  1. Does the response have a SPECIFIC, well-defined shape? If YES and color is only secondary → FC
  2. Does color drive the response but there's still some (vague) shape? → CF
  3. Is there absolutely NO form — the object could literally be any shape? → C

C2. Achromatic Color (C')

Achromatic color is coded when the black, grey, or white features of the blot are used AS COLOR (not as shading/texture). The subject references the darkness or lightness as a color property.

CodeSymbolDefinitionExample
Form-Achromatic ColorFC'Form is primary, achromatic color is secondary"A black cat" (shape defines it, blackness adds to it)
Achromatic Color-FormC'FAchromatic color is primary, form is secondary"Something dark and ominous, kind of shapeless"
Pure Achromatic ColorC'Achromatic color only, no form"Darkness" or "Night" (no shape at all)
CRITICAL DISTINCTION — C' vs Y (Shading): This is one of the MOST COMMON coding errors. The rule from Exner's manual states clearly: "If the intent is not clear when the words 'light' or 'dark' are used, the coding for diffuse shading (Y) is more appropriate."

Code C' when the subject clearly uses black/grey/white AS A COLOR (e.g., "it's black like coal," "it's a white wedding dress")
Code Y when the subject references light/dark gradations for shading effects (e.g., "the lighter parts look fuzzy," "it's shadowy")
WHEN IN DOUBT → Code Y (not C')

D. SHADING DETERMINANTS

Shading determinants are coded when the subject uses the light-dark variations (shading nuances) within the blot to create their percept. There are THREE types of shading:

D1. Texture (T)

Definition: The shading features create a tactile impression — the subject describes how the object would FEEL to touch.

CodeSymbolDefinitionExample
Form-TextureFTForm primary, texture secondary"A furry bear — it looks soft because of the shading"
Texture-FormTFTexture primary, form secondary"Something furry and soft, maybe an animal skin"
Pure TextureTTexture only, no form"It just feels soft/fuzzy" (no shape identified)

Key Words That Signal Texture: furry, soft, rough, smooth, silky, fuzzy, woolly, bumpy, grainy, hairy, velvety, slimy, wet, slippery, coarse

D2. Vista (V)

Definition: The shading features create an impression of depth or dimensionality — things appear to be at different distances (near/far, above/below).

CodeSymbolDefinitionExample
Form-VistaFVForm primary, vista/depth secondary"A valley with mountains in the background — the shading makes it look far away"
Vista-FormVFVista primary, form secondary"It looks like depth, with something vague in the distance"
Pure VistaVVista/depth only, no form"Just depth, like looking into a dark tunnel"
Vista (V) vs Form Dimension (FD): Both create depth/dimensionality, but they use DIFFERENT blot features:
- V (Vista): Uses SHADING (light-dark variations) to create depth
- FD (Form Dimension): Uses SIZE and SHAPE differences to create depth (NO shading involved)

If the subject says "this part looks farther away because it's lighter/darker" → Code V
If the subject says "this part looks farther away because it's smaller" → Code FD

D3. Diffuse Shading (Y)

Definition: The shading features create a general impression of light, dark, or shading without creating texture or depth. It is a diffuse, undifferentiated use of the shading.

CodeSymbolDefinitionExample
Form-Diffuse ShadingFYForm primary, shading secondary"An X-ray — you can see through it because of the shading"
Diffuse Shading-FormYFShading primary, form secondary"Something smoky, with a vague shape"
Pure Diffuse ShadingYShading only, no form"Fog" or "shadows" or "just darkness/lightness"

Key Words That Signal Diffuse Shading: shaded, light, dark (when NOT used as color), shadowy, smoky, foggy, X-ray, transparent, faded, dim, murky

Shading Decision Tree:
1. Is the shading used to describe how something FEELS (touch)? → Code T (Texture)
2. Is the shading used to create DEPTH (near/far)? → Code V (Vista)
3. Is the shading used in a general, diffuse way (light/dark, smoky, transparent)? → Code Y (Diffuse Shading)
4. Is "dark" or "black" used clearly AS A COLOR (not shading)? → Code C' (Achromatic Color)
5. WHEN IN DOUBT between C' and Y → Always code Y

E. FORM DIMENSION (FD)

Symbol: FD

Definition: The response involves an impression of depth or three-dimensionality created SOLELY by the size or shape of objects — NOT by shading.

  • "This person is farther away because they're smaller" = FD
  • "It's a road going into the distance — the narrowing makes it look deep" = FD
  • "One thing is behind the other — the overlap shows depth" = FD
FD has NO form hierarchy — there is no "DF" or "pure D." It is ALWAYS coded as FD. If shading creates the depth impression, code V (Vista), not FD.

F. PAIRS AND REFLECTIONS

F1. Pair (2)

Definition: Two identical objects are reported, based on the bilateral symmetry of the blot. They are the same object seen on both sides.

  • The objects must be identical (same thing on both sides of the blot's axis of symmetry)
  • Coded as (2) — placed after form quality in the code string
  • "Two butterflies" (one on each side) = Pair
  • If the objects are NOT based on symmetry (e.g., "two different things"), do NOT code pair
Pair is coded ONLY when the two objects are based on the bilateral symmetry of the blot. If the subject sees two separate things that happen to be alike but are NOT reflections of each other across the midline, do NOT code pair.

F2. Reflection (Fr, rF)

Definition: The subject identifies an object and its mirror image or reflection, based on the bilateral symmetry of the blot. The subject explicitly states or implies that one side is a reflection of the other.

CodeSymbolDefinitionExample
Form-ReflectionFrForm primary in the reflected object"A person looking at their reflection in water — same shape on both sides"
Reflection-FormrFThe reflection impression dominates, form is vague"Something reflected in water, no clear shape"
Reflection vs. Pair — Key Difference:
- Pair (2): "Two butterflies" — two separate objects that happen to be identical
- Reflection (Fr/rF): "A butterfly and its reflection in water" — ONE object and its mirror image

If the word "reflection," "mirror," "reflected," or "mirror image" is used → Code Reflection
If two identical objects are seen without reflection language → Code Pair
NOTE: When Reflection is coded, Pair is NOT coded for the same response (they are mutually exclusive).
STEP 4: FORM QUALITY (FQ)

Form Quality assesses how well the response matches the contours/shape of the blot area used. It is a measure of perceptual accuracy — how closely the subject's percept "fits" the actual inkblot area.

IMPORTANT: Form Quality is determined by comparing the subject's response to Form Quality Tables in the Exner manual, which list common responses for each specific blot area (location). These tables are based on large normative samples. You CANNOT determine FQ by "just looking at the blot" — you MUST consult the tables.

A. FQ+ (Superior/Overelaborated)

Symbol: +

Definition: The response shows unusually detailed, enriched articulation of form that is clearly evident in the blot. The fit is not only accurate but exceptionally well-specified.

  • The percept fits the blot area extremely well
  • The subject provides additional form detail that enhances the accuracy
  • Rare — very few responses earn FQ+
  • The elaboration must be form-based (not just content elaboration)

Example: "A woman in a Victorian dress with her arms outstretched, you can see the folds of the fabric" — where ALL described features match the blot contours precisely.

B. FQo (Ordinary)

Symbol: o

Definition: The response demonstrates common, readily perceived accuracy — the percept fits the area well and is frequently reported by others.

  • The object clearly fits the blot area
  • Listed as "ordinary" in the FQ tables for that specific location
  • Most responses in a typical protocol should be FQo
  • Indicates accurate, conventional perception

Example: Card V, whole — "A bat" = FQo (listed as ordinary for W on Card V)

C. FQu (Unusual)

Symbol: u

Definition: The response is uncommon but can be readily seen — the fit is reasonable when pointed out, even though it is not frequently given.

  • Not listed as "ordinary" in the FQ tables but is a legitimate fit
  • When the examiner looks at the blot, they CAN see how it fits
  • It is an idiosyncratic but NOT distorted perception
  • The contours of the blot area DO support the percept

Example: Card I — "A jack-o-lantern" (center area) — uncommon but the shape supports it = FQu

D. FQ- (Minus/Distorted)

Symbol: -

Definition: The response demonstrates poor, distorted perception — the percept does NOT fit the contours of the blot area used. The shape of the blot does not support the response.

  • The object simply does NOT match the blot area's contours
  • Even when explained, the examiner cannot see how it fits
  • The form is imposed on the blot rather than derived from it
  • Indicates distorted or inaccurate perception

Example: Card V, whole — "A giraffe" — the shape of the whole Card V does not look like a giraffe = FQ-

Common Error — Overuse of FQ-: Less experienced coders tend to assign FQ- too frequently because they don't consult the FQ tables carefully. Many responses that seem unusual are actually FQu (unusual but legitimate fit). Always check the tables before assigning FQ-.

E. FQ none (No Form)

Symbol: (no FQ assigned or "none")

Definition: The response has no form demand — the determinant is pure C, pure T, pure Y, pure V, or pure C'. Since there is no form to evaluate, FQ cannot be assessed.

  • Applied ONLY to formless responses (Pure C, Pure T, Pure Y, Pure V, Pure C')
  • "Blood" (pure C, no shape) — no FQ can be assigned
  • "Softness" (pure T, no shape) — no FQ can be assigned

F. How to Determine Form Quality — Step by Step

  1. Identify the EXACT location (blot area) used for the response
  2. Look up that location in the FQ Tables for that card in the Exner manual
  3. Check if the response content is LISTED for that location:
    • If listed as "o" → code FQo
    • If listed as "u" → code FQu
    • If listed as "-" → code FQ-
  4. If the response is NOT listed at all in the tables:
    • Examine whether the contours of the area support the percept
    • If yes (you can see the fit) → code FQu
    • If no (the fit is impossible or grossly distorted) → code FQ-
  5. For FQ+: the response must be listed AND the subject provides additional form detail that enriches accuracy beyond the ordinary
FQ is LOCATION-SPECIFIC: The same content (e.g., "butterfly") may be FQo in one location and FQ- in another. A "butterfly" seen in the whole of Card V = FQo. A "butterfly" seen in a tiny side detail of Card IV might = FQ-. ALWAYS check the specific location.

STEP 7: SPECIAL SCORES (CRITICAL SECTION)

Special Scores identify unusual features in the verbal material or the cognitive processes revealed by the response. They are divided into Cognitive Special Scores, Affective/Thematic Special Scores, and Other Special Scores.

Special Scores are among the most commonly MISSED codes (errors of omission). Always carefully review the verbatim response and inquiry for evidence of unusual verbalization, illogical thinking, or thematic content that warrants a special score.

A. COGNITIVE SPECIAL SCORES (Thinking Disturbance)

These scores reflect varying degrees of disturbed thinking, faulty logic, or unusual verbalization. They are organized in a hierarchy from mild to severe:

A1. Deviant Verbalization (DV) — Level 1 and Level 2

Definition: The subject uses a word or phrase incorrectly — either a neologism (made-up word) or a redundancy (saying the same thing twice unnecessarily).

TypeDefinitionExampleLevel
NeologismA word that doesn't exist or is used in a clearly wrong way"A wingish thing" or "It's very humanoid-like"DV1 (mild)
RedundancyUnnecessary repetition of meaning"A tiny little small bug" or "It's a pair of two things"DV1 (mild)
Bizarre NeologismA word so bizarre or distant from meaning that it suggests serious cognitive slippage"It's a flimdingle" or "The armpitated section"DV2 (severe)
DV1 is mild and common even in normal protocols. DV2 is severe and suggests significant cognitive disturbance. The distinction depends on HOW bizarre or inappropriate the verbalization is.

A2. Deviant Response (DR) — Level 1 and Level 2

Definition: The subject makes an inappropriate, tangential, or circumstantial remark that goes beyond what is needed to identify the response.

TypeDefinitionExampleLevel
Inappropriate PhraseAn aside or comment unrelated to the task"A bat — I used to be afraid of those as a kid, my mother would scream"DR1 (mild)
Circumstantial ResponseRambling that strays far from the response"It's like a pelvis... reminds me of when I had my hip surgery three years ago in that hospital on Main Street..."DR1 (mild)
Bizarre TangentA comment so disconnected that it suggests serious cognitive slippage"A butterfly — they have them on Mars you know, the blue ones"DR2 (severe)

A3. Incongruous Combination (INCOM/INC) — Level 1 and Level 2

Definition: A single object is described with features or attributes that are incongruous or impossible — features that don't go together in reality.

LevelDefinitionExample
INC1 (Level 1)An object with inappropriate features — mildly incongruous"A butterfly with human hands" or "A red bear" (when referring to real animal)
INC2 (Level 2)A grossly impossible combination of features — severely incongruous"A headless person who is talking" or "A fish with tree branches growing from it"
INC is about ONE object with wrong features. The key: can this combination exist in reality? "A blue dog" = INC1 (unusual but not impossible — blue heelers exist, could be colored). "A dog with wings" = INC1-2 depending on context (could be fictional). "A talking tree with human legs" = INC2.

A4. Fabulized Combination (FABCOM/FAB) — Level 1 and Level 2

Definition: Two or more objects are combined in an impossible or implausible relationship with each other.

LevelDefinitionExample
FAB1 (Level 1)Two objects in an implausible but not truly impossible relationship"Two chickens holding up a building" or "A bug carrying a mountain"
FAB2 (Level 2)Two objects in a grotesquely or bizarrely impossible relationship"Two elephants growing out of a person's head" or "A worm swallowing a planet"
INC vs FABCOM — Key Distinction:
- INC: ONE object with wrong features (attribute problem): "A cat with wings"
- FABCOM: TWO objects in a wrong relationship (relational problem): "A cat sitting on top of the moon"

Ask yourself: Is it ONE thing with impossible parts (INC) or TWO things in an impossible relationship (FABCOM)?

A5. Contamination (CONTAM)

Definition: The MOST severe cognitive special score. Two or more impressions are fused into a single response in a way that violates reality. The percept is a merger of two distinct concepts into one.

  • Two objects literally occupy the same blot space and are fused together
  • "It's a butterfly-person" (NOT a butterfly AND a person, but a single fused entity)
  • "A blood island" (where blood and island are fused as one concept, not blood ON an island)
  • Extremely rare in non-psychotic individuals
CONTAM is the most severe thinking disturbance score. It indicates a fusion of two separate perceptions into one without awareness that this is illogical. It is ALWAYS Level 2 severity. It is rare and should be coded very carefully — make sure it's truly a fusion (one merged entity) and not just a FABCOM (two things in an impossible relationship).

A6. Inappropriate Logic (ALOG)

Definition: The subject uses clearly strained or inappropriate reasoning to justify their response without being prompted to do so.

  • The subject spontaneously offers reasoning that is clearly faulty
  • "It must be a king because it's in the middle" (positional logic)
  • "It's bigger so it must be the mother" (size logic applied inappropriately)
  • "This has to be blood because it's red" (color used as exclusive proof)
ALOG is coded when the subject SPONTANEOUSLY offers faulty reasoning. If the examiner's inquiry question PROMPTS the justification, be cautious about coding ALOG — the flawed logic must be offered freely.

Summary: Cognitive Special Scores — Severity Hierarchy

B. AFFECTIVE/THEMATIC SPECIAL SCORES

B1. Morbid Content (MOR)

Definition: The response attributes death, damage, destruction, dysphoria, or decay to the percept.

  • Code MOR when: An object is identified as dead, broken, ruined, damaged, decaying, torn, destroyed, hurt, wounded, spoiled, old and worn out
  • Also code MOR when: A clearly dysphoric quality is attributed ("a sad tree," "a depressed-looking face")

Examples:

  • "A dead butterfly" = MOR
  • "A broken vase" = MOR
  • "A wilted, dying flower" = MOR
  • "Parts of a body that are in a state of decay" = MOR
  • "A sad-looking clown" = MOR
  • "A person who has been squashed" = MOR

B2. Aggressive Movement (AG)

Definition: The response involves an action that is clearly aggressive — one object actively hurting, attacking, or destroying another, or engaging in aggressive activity.

  • The aggression must be ONGOING (happening right now), not past or potential
  • "Two people fighting" = AG
  • "A lion attacking a zebra" = AG
  • "An explosion destroying a building" = AG
  • Do NOT code AG for: "A mean-looking person" (no aggressive ACTION) or "A person who was stabbed" (past tense = MOR, not AG)
AG requires ACTIVE, ONGOING aggression. If the aggression already happened (past tense), it is likely MOR, not AG. "Two people fighting" = AG. "A person who was beaten up" = MOR (damage already done).

B3. Cooperative Movement (COP)

Definition: The response involves two or more objects engaged in clearly cooperative, positive interaction.

  • "Two people dancing together" = COP
  • "Two angels helping each other" = COP
  • "Animals working together to build something" = COP
  • The interaction must be CLEARLY positive/cooperative — neutral interactions (e.g., "two people looking at each other") do NOT qualify

C. OTHER SPECIAL SCORES

C1. Perseveration (PSV)

Definition: The subject gives the same response repeatedly across different cards or within the same card. There are three types:

  • Within-Card Perseveration: Same content given to different areas of the same card using the same determinant and DQ
  • Content Perseveration: The same content appears repeatedly across cards (the exact same specific content, not just general category)
  • Mechanical Perseveration: Identical response given to consecutive cards (same location, determinant, content — essentially a copy)

C2. Personal (PER)

Definition: The subject references personal knowledge or experience to justify or elaborate the response.

  • "It looks like a bat — I studied them in biology class"
  • "That's a pelvis — I know because I'm a nurse"
  • "Looks like the mountains near my home"

C3. Abstract Content (AB)

Definition: The response is a clearly abstract concept that is represented by the use of color or form. The subject uses the blot to represent an abstract idea.

  • "This represents evil — the darkness symbolizes it" = AB
  • "It's a painting of sadness" = AB
  • "The colors represent happiness and joy" = AB
  • Must be a CLEAR abstraction, not just a vague response

C4. Color Projection (CP)

Definition: The subject identifies chromatic color in an area of the blot that is actually achromatic (black, grey, or white). They "project" color onto a colorless area.

  • "This is a beautiful blue bird" (said about a black area) = CP
  • Very rare

C5. Good Human Representation (GHR) and Poor Human Representation (PHR)

Definition: Every response containing human content (H, (H), Hd, (Hd), Hx) or human movement (M) is coded as EITHER GHR or PHR based on a decision algorithm:

  • GHR: Response meets criteria for adaptive human representation (good form quality, no cognitive special scores, no aggressive/morbid content)
  • PHR: Response has poor form quality, contains cognitive special scores, AG, or FABCOM, or other indicators of maladaptive representation
GHR/PHR Decision Rules (simplified):
1. If FQ is + or o, AND no cognitive special scores (DV2, DR2, INC2, FAB2, ALOG, CONTAM), AND no AG or MOR → code GHR
2. If FQ is -, OR contains Level 2 cognitive special scores, OR FABCOM, OR ALOG, OR CONTAM → code PHR
3. For other combinations, additional decision rules apply (consult the Exner tables for the complete algorithm)
STEP 8: MULTIPLE CODING RULES (BLENDS)

When a single response involves more than one determinant, it is called a BLEND. Blends are coded with all contributing determinants separated by periods (dots).

When to Assign Multiple Determinants

  • A blend is coded when TWO OR MORE different determinant categories contribute to the SAME response
  • Each determinant must have clear evidence from the response or inquiry
  • Example: "A red butterfly flying" — The subject uses FORM (shape), COLOR (red), and MOVEMENT (flying) → coded as Ma.FC

Blend Coding Format

Determinant1 . Determinant2 . Determinant3
(separated by periods/dots)

Examples of Blends:

  • "A furry black bear" (form + texture + achromatic color) = FT.FC'
  • "Smoke rising from a fire" (movement + diffuse shading + form) = ma.FY (with Fi content)
  • "Two people in colorful costumes dancing" (human movement + color) = Ma.FC
  • "A woman tied to a stake with smoke all around her" (from the Exner manual example) = M.m.YF

Priority/Sequencing Rules for Blends

  1. Movement determinants are listed FIRST (M before FM before m)
  2. Then chromatic color (FC, CF, C)
  3. Then achromatic color (FC', C'F, C')
  4. Then shading (FT/TF/T, then FV/VF/V, then FY/YF/Y)
  5. Then Form Dimension (FD)
  6. Then Pair/Reflection (Fr, rF)
Common Blend Error: Forgetting to include a determinant in a complex blend is one of the most common errors of omission identified in the Exner manual. After coding a blend, always re-read the verbatim response and inquiry to check: "Did I capture ALL the perceptual features the subject used?"

Special Blend Types (Important for Structural Summary)

Blend TypeDefinitionExample
Color-Shading BlendA blend containing BOTH a chromatic color determinant AND a shading determinant (T, V, or Y) or achromatic color (C')CF.FC' or FC.FY
Shading BlendA blend containing TWO OR MORE different shading determinants (any combination of T, V, Y, C')FT.FY or FC'.FV
m and Y BlendA blend containing both inanimate movement (m) and diffuse shading (Y) — indicates situational stressma.YF
Pure F is NEVER in a blend. If any other determinant is present, it is no longer "pure" form. If form is used together with color, it becomes FC/CF. If form is used with movement, it becomes M/FM/m (which inherently have form). Pure F means ONLY shape was used — nothing else.

Z Score (Organizational Activity)

Z scores are assigned when the subject organizes parts of the blot into a meaningful relationship. Z scores are assigned for:

  • ZW: Any W response (the entire blot was organized)
  • ZA: Two or more adjacent D areas are integrated
  • ZD: Two or more distant D areas are integrated
  • ZS: White space is integrated with adjacent blot areas

Each card has specific Z values for each type (listed in the Z tables in the manual). The sum of all Z scores = Zsum. The expected Z for a given Zf = Zest.

Zd = Zsum - Zest
(Difference between actual and expected organizational activity; indicates over- or under-incorporation)

The Exner manual specifically identifies these coding errors. Being aware of them can prevent cascading interpretation errors:

STEP 11: PRACTICE EXAMPLES

Practice Example 1

Card V — Response:

Response: "A bat"

Inquiry: "The whole thing — the wings out to the side, the head up here, the legs at the bottom. Just the shape of it."

Step-by-Step Coding:

  1. Location: Whole blot used → W
  2. DQ: Single specific object, no integration of separate parts → o (ordinary)
  3. Determinant: Only shape mentioned ("just the shape") → F (pure form)
  4. Form Quality: Bat on W of Card V → check tables → o (ordinary — it's listed)
  5. Pair: One bat, not two → no pair
  6. Content: Bat is a whole animal → A
  7. Popular: Bat on Card V whole = Popular → P
  8. Z Score: W response on Card V → Z = 1.0
  9. Special Scores: Nothing unusual → none

Final Code: Wo Fo A P 1.0

Practice Example 2

Card II — Response:

Response: "Two bears fighting, with blood between them"

Inquiry: "These dark parts on the sides are the bears — they're pushing against each other. The red in the middle is blood, it's red so it looks like blood."

Step-by-Step Coding:

  1. Location: Uses the common dark lateral areas (D1) plus center red (D3) → this uses multiple D areas in combination → W+ (or D+ if not using entire blot — check location sheet)
  2. DQ: Two objects in meaningful relationship (fighting) + blood related to them → + (synthesized)
  3. Determinants:
    • Bears are in action (fighting) — animal doing natural animal activity → FMa (animal movement, active)
    • Blood identified by red color → C (pure color — "it's red so it looks like blood" = color only, no form for the blood)
    • This is a BLEND: FMa.C
  4. Form Quality: Bears in D1 of Card II → check tables → likely o
  5. Pair: "Two bears" — identical, based on symmetry → (2)
  6. Content: Bears = whole animal; Blood = blood → A, Bl
  7. Popular: Animal in D1 of Card II = Popular → P
  8. Z Score: W+ on Card II → Z score per table
  9. Special Scores: Bears are fighting = AG (aggressive movement) → AG

Final Code: W+ FMa.Co (2) A, Bl P 4.5 AG

Practice Example 3

Card VI — Response:

Response: "An animal skin, like a bearskin rug"

Inquiry: "The whole thing — it's flat and spread out like a hide. The shading makes it look furry, soft to the touch."

Step-by-Step Coding:

  1. Location: Whole blot → W
  2. DQ: Single object, specific shape → o
  3. Determinants:
    • Shape is mentioned (flat, spread out) → Form
    • "Shading makes it look furry, soft to the touch" → Texture (FT) — tactile quality from shading
    • Form is primary (it has the shape of a hide), texture is secondary → FTo
  4. Form Quality: Animal skin/hide on W of Card VI → check tables → o
  5. Pair: One skin → no pair
  6. Content: Animal skin → Ad (it's a PART of an animal — the skin)
  7. Popular: Animal skin/hide on Card VI = Popular → P
  8. Z Score: W on Card VI → Z = 2.5
  9. Special Scores: None

Final Code: Wo FTo Ad P 2.5

This Card VI response is specifically highlighted in the Exner manual as critical. Failing to code FT here (when the subject clearly mentions the furry/soft/tactile quality from shading) would result in T=0 in the structural summary, which cascades into errors in the interpersonal cluster, es, Adjusted D, and multiple indices.

Practice Example 4

Card III — Response:

Response: "Two people picking something up together"

Inquiry: "The dark figures on the sides — they're bending over, reaching for this thing in the middle. The shape of them — you can see their heads, bodies, and legs."

Step-by-Step Coding:

  1. Location: Common lateral dark figures (D1 or D9) → D
  2. DQ: Two objects in meaningful relationship (cooperating to pick something up) + object being picked up → + (synthesized)
  3. Determinants:
    • People performing a human action (bending, reaching, picking up) → Ma (human movement, active)
    • Only shape is mentioned beyond the movement → form is subsumed in M
  4. Form Quality: Two people in D1 of Card III → check tables → o
  5. Pair: "Two people" — identical, based on symmetry → (2)
  6. Content: Two whole human figures → H
  7. Popular: Two human figures on Card III = Popular → P
  8. Z Score: D+ integration → Z per table
  9. Special Scores: Cooperative activity → COP

Practice Example 5 — Complex Blend

Card IX — Response:

Response: "A colorful explosion, with fire and smoke going everywhere, it's all chaotic and destructive"

Inquiry: "All of it — the oranges and greens are the fire, the lighter parts are smoke rising up, the whole thing is just blasting outward"

Step-by-Step Coding:

  1. Location: Whole blot → W
  2. DQ: Integration present (fire + smoke in relationship) but some components are formless → v/+
  3. Determinants:
    • "Blasting outward" = inanimate movement → ma
    • "The oranges and greens are the fire" = chromatic color, vague form → CF
    • "Lighter parts are smoke rising" = diffuse shading + vague form → YF
    • BLEND: ma.CF.YF
  4. Form Quality: Explosion on W of Card IX → likely u
  5. Content: Explosion + Fire → Ex, Fi
  6. Popular: Not a Popular for Card IX → no P
  7. Z Score: W on Card IX → Z per table
  8. Special Scores: "Chaotic and destructive" — is this MOR? The explosion is described as destructive → MOR

Final Code: Wv/+ ma.CF.YFu Ex, Fi 5.5 MOR

5 HIGH-YIELD VIVA POINTS

Frequently Asked Coding Rules

1. The Step-Down Principle

  • When in doubt between FC and CF → code CF
  • When in doubt between CF and C → code CF (not C)
  • When in doubt between C' and Y → code Y
  • When in doubt between FV and FD → determine if SHADING is used (V) or only size/position (FD)
  • Principle: Always step down to the less pathologically significant code when ambiguity exists

3. Color Hierarchy Rules (Viva Favorite)

The FC : CF : C Continuum
  • FC — Maximum form, minimum color: "A red butterfly" (butterfly has definite shape; red is secondary)
  • CF — Moderate form, dominant color: "A splash of paint, reddish" (color drives it; vague form)
  • C — No form, only color: "Blood" (on a red area — any shape = blood; only color matters)

Clinical Significance (brief, for viva): FC = well-modulated affect; CF = less controlled emotion; C = raw, unmodulated emotional discharge. Higher FC:CF+C ratio = better emotional control.

4. When NOT to Code Movement

  • "A person" (just identified, no action described) → NO movement, just F
  • "A dead bird" → NO movement (dead = MOR, not FM)
  • "A butterfly" (without any action) → NO movement, just F
  • "Footprints" → NO movement (the person is gone; these are just marks)

5. The Barely Yield Phenomenon (From the Exner Manual)

The Exner manual specifically discusses the "barely yield phenomenon" — when a structural finding barely reaches a threshold (e.g., Adjusted D is barely zero or barely minus). In these cases:

  • Go back and REVIEW the coding of responses that contribute to that variable
  • Check for possible coding errors that might have tipped the value one way or the other
  • A single coding error in these situations can completely change the interpretive conclusion
  • This is why coding accuracy is so critical

6. Lambda and Pure F — Key Points

  • Lambda = Pure F responses divided by (Total R - Pure F responses)
  • Lambda > 0.99 = significant (avoidant style or situational defensiveness)
  • When Lambda > 0.99 AND EA < 4.0 AND R < 17 → likely situational defensiveness (invalid record)
  • When Lambda > 0.99 AND EA >= 4.0 OR R > 16 → likely avoidant STYLE

! ADDITIONAL CAUTIONS & IMPORTANT NOTES

Never Code from Memory: Always have the verbatim protocol, location sheet, and FQ tables in front of you when coding. Do not code from memory or paraphrase.
Never Add Determinants Not Articulated: A determinant is coded ONLY if the subject provides evidence that the blot feature contributed to the response. If you THINK color was used because the area is colored, but the subject never mentions color — do NOT code color.
Re-Check the Inquiry: Information from both the Response Phase AND the Inquiry are used together. Sometimes critical determinant information appears ONLY in the inquiry. Always read both phases before coding.
Card-Turning Effects: If a subject turns the card, note the position (rotated, inverted). This can affect location coding. Record card position using the standard notation system.
Multiple Responses per Card: Each separate response to a card is coded independently. A subject may give 1 response or 5 responses to a single card. Each one gets its own complete code line in the Sequence of Scores.
R (Total Number of Responses): Only TRUE responses are counted. Rejected cards (subject says "I don't see anything") are NOT counted. Comments or questions are NOT responses. A response must involve identifying what the blot (or part of it) looks like.
The Number of Responses (R) Matters: Records with fewer than 14 responses should be considered potentially invalid (the Exner system typically requires R >= 14 for reliable interpretation). If R < 14, consider re-administration. However, even brief protocols are still coded using the same rules.
Final Coding Verification: Per the Exner manual — "it is probably wise for any interpreter to review the coding of all responses before proceeding to the interpretation. This is not necessarily to challenge the scoring that has been assigned, but simply to try to ensure that omission or commission errors have not occurred."
