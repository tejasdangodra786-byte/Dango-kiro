High-yield revision only. Verify exact cut-offs against the current manual. Interpret variables in combination, never singly.

Basics & History

  • 10 inkblots; 5 achromatic (I,IV,V,VI,VII), 5 chromatic (II,III,VIII,IX,X).
  • H. Rorschach, Psychodiagnostik 1921; 5 systems (Beck, Klopfer, Hertz, Piotrowski, Rapaport–Schafer); Exner CS 1974; SCZI→PTI; later R-PAS.
  • 2 phases: Response ("what might this be?") + Inquiry (location/determinant/content).
  • R < 14 = invalid → readminister.
  • 3 data sets: verbiage, sequence, structural.

Location & DQ

  • W whole · D common detail · Dd unusual detail · S white space (opposition).
  • DQ: + synthesized · o ordinary · v/+ vague-synth · v vague.

Determinants

  • F form (control/economy → Lambda).
  • M human-mvt = ideation/fantasy; FM = need-driven; m = situational stress. (a/p = active/passive)
  • Chromatic: FC (modulated) · CF · C (raw) · Cn.
  • Achromatic C′ = constrained/suppressed affect.
  • Shading: T closeness/attachment · V painful self-scrutiny · Y anxiety/helplessness.
  • FD self-inspection · (2) pair · Fr/rF reflection (narcissism).
  • Blend = ≥2 determinants (complexity); colour-shading blend = ambivalent/painful affect.

Form Quality & Mediation

  • FQ: + superior · o ordinary · u unusual · − distorted.
  • XA% >.89 · WDA% >.85 · X−% <.15 · P ≈5–7.
  • X−% high & WDA% low = pervasive reality-testing failure.

Organization (Z)

  • Zf = effort; Zd = ZSum − Zest = efficiency.
  • Zd > +3 overincorporative (cautious/inefficient); Zd < −3 underincorporative (hasty/careless).

Core Ratios (Controls)

  • Lambda = F/(R−F); >0.99 = avoidant.
  • EB = M:WSumC → Introversive / Extratensive / Ambitent. (invalid if EA<4)
  • EA = M+WSumC (resources); EBPer ≥2.5 = pervasive.
  • eb = (FM+m):(C′+T+V+Y); es; Adj es.
  • D = current control; Adj D = trait control. Minus = overload/impulsivity. D<AdjD = situational stress.

Cluster Variables

  • Affect: Afr (.50–.80), FC:CF+C, Pure C, SumC′:WSumC, S, Blends, CP, DEPI.
  • Ideation: EB, a:p, Ma:Mp, MOR, Sum6/WSum6, M−, 2AB+Art+Ay.
  • Self: 3r+(2)/R (.33–.45), Fr+rF, FD, V, An+Xy, MOR, H:(H)+Hd+(Hd).
  • Interpersonal: COP, AG, GHR:PHR, T, PureH, Isolation, a:p, Fd, PER.
  • Processing: Zf, W:D:Dd, W:M, Zd, DQ, PSV.

Interpretation Steps

  1. Validity (R≥14) + check coding.
  2. S-CON.
  3. First positive Key Variable sets cluster order (PTI>3, DEPI>5, CDI>3, D<AdjD, AdjD−, L>.99, Fr+rF>0, EB style, p>a+1, HVI).
  4. Else use Tertiary Variables.
  5. Interpret clusters in combination; Cognitive Triad (Process→Mediation→Ideation) & Self+Interpersonal go together.
  6. Integrate with sequence + verbiage.
