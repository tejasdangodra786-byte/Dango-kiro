Short- & Long-Term Goals in Psychotherapy Notes — One-Page Clinical Reference

Evidence-informed guide: writing goals, modality differences, and disorder-specific examples. Grounded in Beck (CBT), Linehan/Van Dijk (DBT), Foa (ERP), CBTp, GAD workbook, MET manual, ICD-10/11 + current documentation standards. External sources paraphrased for licensing compliance.

1 · Core Hierarchy

TermMeaning
ProblemClinical need in client's words + diagnosis
Long-Term GoalBroad functional outcome by discharge (life outside therapy)
Short-Term Goal / ObjectiveMeasurable, time-bound step toward the LTG
InterventionWhat the clinician/program does (modality, technique, frequency)

STG vs LTG: LTGs are aspirational & functional ("what does recovery look like?"), achieved over months–year, reviewed at discharge. STGs are operational & measurable ("what changes in weeks to prove progress?"), reviewed every 30–90 days. One LTG → 2–4 STGs. Goals belong to the client; objectives show change; interventions are what you do.

2 · SMART Framework

LetterMake it…
SpecificExact behavior/symptom named
MeasurableNumber, scale, frequency, observable
AchievableRealistic for client's stage/resources
RelevantTied to problem + client's values
Time-boundStates review/target date

Rule: vague ("improve mood") → insurance denial; too rigid → constant rewrites. Aim specific but flexible.

"[Client] will [behavior/symptom change] as measured by [tool] from [baseline] to [target] by [date], using [intervention]."

3 · Golden Thread

One continuous narrative: assessment → diagnosis → plan goals → interventions → progress notes. A reviewer should trace one story proving medical necessity.

  • Every progress note references the specific goal worked.
  • Document the metric change (PHQ-9, GAD-7…) behind the goal.
  • GIRP note opens on the objective being addressed.
  • Goal not worked = broken plan or note (#1 audit fail).

4 · Build Steps

  • 1. Start from assessment (impairments + client words).
  • 2. Attach diagnosis (ICD/DSM) for medical necessity.
  • 3. Draft the LTG (functional destination) first.
  • 4. Decompose into 2–4 STGs with baseline/target/date.
  • 5. Record a baseline metric.
  • 6. Select evidence-based interventions by Dx + modality.
  • 7. Set review dates (30/60/90 days).
  • 8. Co-create with client (values, strengths, barriers).
  • 9. Revise — don't abandon — stalled/accelerated goals.

5 · Goals by Modality key differences

ModelFocus / Signature structure
CBTPresent, time-limited; symptoms/thoughts/behaviors → SMART targets + homework
DBTTarget hierarchy: life-threatening → therapy-interfering → quality-of-life → skills
ERP (OCD)Climb fear/exposure hierarchy + response prevention
PsychodynamicInsight, relational/character patterns; operationalize insight as verbalized/enacted
MI / METMotivation & ambivalence; match stage of change
Family/CouplesSystem/communication patterns; dyadic objectives (↓ expressed emotion)
Phase-based traumaPhase-gated: safety → processing → integration

6 · Goals by Disorder (SMART examples)

Depression (MDD): LTG — maintain remission + return to functioning ≥3 mo. STG — PHQ-9 18→≤9 in 12 wks; ≥3 BA activities/wk; ≥3 thought records/wk.

GAD: LTG — manage worry without avoidance. STG — GAD-7 15→≤8 in 10 wks; worry episodes →≤3/wk; relaxation 5×/wk.

Panic: LTG — end panic-driven avoidance. STG — attacks 4→≤1/wk in 8 wks; weekly interoceptive exposure.

OCD: LTG — ≥35% Y-BOCS reduction + restored functioning. STG — build hierarchy wk 2; graded exposures w/ full RP; ↓ ritual time.

PTSD / C-PTSD (phase-gated): P1 safety + affect regulation, ↓ flashbacks; P2 trauma processing (CPT/PE), ↓ PCL-5; P3 reconnection.

Substance Use: LTG — sustain recovery goal + relapse-prevention. STG — resolve ambivalence/set quit date (MET); trigger plan; supports X×/wk; treat co-occurring Dx.

Personality (BPD): longer course. LTG — "life worth living." STG (DBT hierarchy) — eliminate self-harm first; ↓ therapy-interfering; skills + diary cards.

Psychosis/Schizophrenia: LTG — ↓ distress/impact + community functioning. STG — ↓ conviction/distress of target symptom (CBTp); ↑ daily activity; family ↓EE; adherence.

Anger: LTG — manage without aggression. STG — ↓ aggressive episodes; use DBT skills (opposite action, TIPP, PLEASE); spot early cues.

Child/Adolescent: developmentally appropriate, observable, caregiver/school-involved; use CBCL, VSMS; tie to home/school functioning.

7 · Review & Measure

  • Review every 30/60/90 days or per payer rules.
  • Re-administer the baseline tool; log the score trend.
  • Each note: goal → intervention → response → plan.
  • Stalled? Re-check goal fit, dose, barriers, Dx, engagement — then revise.
  • Discharge: consolidate gains + relapse-prevention plan.
