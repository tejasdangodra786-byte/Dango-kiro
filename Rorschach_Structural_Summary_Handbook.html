Part IWhat is the Structural Summary?

The Structural Summary is the single page (front, plus a "Sequence of Scores" and constellation section) on which every coded variable of a protocol is tallied, combined into ratios and percentages, and converted into derived scores and indices. It is the statistical skeleton of the record.

1. What it is

A structured worksheet with three regions: (a) the upper section of frequency tallies (Location, DQ, Determinants, Contents, FQ, Z, Special Scores, Approach); (b) the lower section of computed variables grouped into seven clusters — Controls, Affect, Processing, Mediation, Ideation, Self-Perception, Interpersonal; and (c) the constellations (PTI, DEPI, CDI, S-CON, HVI, OBS).

2. Why it is created

Because interpretation is data-driven, not impressionistic. Ratios such as EB, EA:es, and Afr only become meaningful once every contributing frequency is counted exactly. The Summary makes the whole record computable and auditable.

3. How it differs from the response record

The response record is the verbatim answers plus inquiry. It contains words; the Structural Summary contains numbers derived from the coding of those words.

4. How it differs from the coding (sequence-of-scores) sheet

The Sequence of Scores lists each response in order with its full code string (Location, DQ, Determinants, FQ, (2), Content, P, Z, Special). The Structural Summary aggregates those code strings into totals — it loses the per-response order but gains the frequencies needed for formulas.

5. How it differs from interpretation

Interpretation is the clinical narrative built after the Summary is computed and validated. The Summary is arithmetic; interpretation is meaning.

6. Why raw coding must be accurate first

One coding error cascades. Missing a single FT on the Card VI Popular can make SumT = 0, which changes es, then D, then AdjD, then the HVI prerequisite, then S-CON. Garbage in, garbage out.

Part IVResponse Frequency (R)

R — Total Responses
R = total number of scorable responses in the record

Count each scored response once. Extra responses that appear only during the Inquiry (not in the first, free-response phase) are generally not added to R.

Example
Card I: 2 responses Card II: 1 Card III: 2 Card IV: 1 Card V: 2 Card VI: 1 Card VII: 2 Card VIII: 3 Card IX: 1 Card X: 3 -------------------- R = 2+1+2+1+2+1+2+3+1+3 R = 18

Special cases for R

SituationWhat to do
R is very lowBe careful — a very short record may not support full interpretation (see Part XXVIII). Use the set minimum; do not make up a cut-off.
R is very highHigh productivity inflates several frequencies; watch percentages that use R as denominator.
Borderline RProceed but flag; re-check whether the administration prompted enough responses.
Fewer responses than expectedConfirm none were lost in recording; verify card-by-card.
Multiple responses to one blotAll are counted; each is coded independently.
Omitted / rejected cardRecord the rejection; it does not add to R but is clinically noted.
Testing terminated earlyNote incompleteness; validity may be compromised.
Do not make up cut-offs. The smallest R that still allows interpretation is a fixed, published figure — use that exact number as it is written.

Part VLocation — W, D, Dd, S

CodeMeaningHow to tally
WWhole blot used (nothing meaningful omitted)Count every response coded W (including WS)
DCommon detail (a listed, frequently-used area)Count every D and DS
DdUnusual detail (any area not W or D)Count every Dd and DdS

Avoid double-counting. Each response contributes one location (W or D or Dd). The S tally is additional — WS adds 1 to W and 1 to S. So W + D + Dd = R, while S is counted on top.
Fictional protocol — location tally (R = 10)
1 → W 6 → WS 2 → D 7 → D 3 → Dd 8 → Dd 4 → D 9 → DS 5 → W 10 → D W = responses 1,5,6 → W = 3 D = responses 2,4,7,9,10 → D = 5 Dd = responses 3,8 → Dd = 2 S = responses 6,9 → S = 2 (added on top) Check: W + D + Dd = 3 + 5 + 2 = 10 = R ✓

Location cautions

  • WS, DS, DdS — the S is a modifier; tally the base location and the S.
  • Multiple location claims ("the whole thing" but only part described in inquiry) → code what was actually used.
  • S is never a stand-alone location code.
  • When ambiguous, the exact coding rule (verified in inquiry against the location table) decides the Summary entry.
W + D + Dd must equal R. If it does not, a location code was missed or duplicated — fix it before continuing.

Part VIDevelopmental Quality (DQ)

SymbolNameMeaning
+SynthesisedTwo or more discrete areas/parts meaningfully integrated; all with form demand
oOrdinaryA discrete object with specific form demand; no integration
v/+Vague/SynthesisedIntegration present, but ≥1 component is formless
vVagueNo form demand (cloud, smoke, blood-without-shape) and no integration

How DQ enters the Summary

Tally the count of each: DQ+, DQo, DQv/+, DQv. Their sum equals R. DQ+ feeds processing interpretation; DQv is watched for developmental immaturity.

Example (R = 6)
1 "two people lifting a basket" → + 2 "a bat" → o 3 "clouds around a peak" → v/+ 4 "smoke" → v 5 "a butterfly" → o 6 "a woman wearing a hat" → + DQ+ = 2 DQo = 2 DQv/+ = 1 DQv = 1 Check: 2+2+1+1 = 6 = R ✓

Handling uncertainty

Use the decision tree: Are ≥2 parts meaningfully related? If yes → do all parts have form? Yes = +, No = v/+. If not related → does the single object have definite shape? Yes = o, No = v.

Part VIIDeterminants

Determinants are the blot features that formed the response. A response has one determinant (single) or several (a blend, joined by periods, e.g. ma.FY).

FamilyCodesNotes for tallying

Chromatic colorFC, CF, CStep-down when in doubt (FC→CF→C). Feed WSumC.
Achromatic colorFC', C'F, C'Feed SumC' (right side of eb, es).
Shading — VistaFV, VF, VDepth from shading. Feed SumV.
Shading — TextureFT, TF, TTactile. Feed SumT.

Determinant tally method

1
Locate every occurrence of the determinant in the Sequence of Scores — including inside blends.
2
Count it (each blend contributes to each of its determinants).
3
Enter the frequency in the Summary column.
4
Verify the total against the response record.
5
Compute weighted values where required (WSumC uses weights below).
6
Transfer to the derived-variable section (EB, eb, es…).
Weighted Sum of Color (WSumC)
WSumC = (0.5 × FC) + (1.0 × CF) + (1.5 × C)

These chromatic-color weights (FC = 0.5, CF = 1.0, C = 1.5) are the standard Comprehensive System weights; they are the right side of the EB and the whole of the affect side of EA. Cn (color naming), where present, is weighted with C.

Multiple determinants (blends)

  • A blend is counted once as a response but each determinant it contains is tallied in its own column.
  • A response is a blend only if two or more different determinants genuinely contributed (evidenced in the record).
  • The Blends:R tally counts responses containing ≥2 determinants.
  • A Color-Shading blend (chromatic color + any shading or C') is flagged separately (affect ambivalence; S-CON variable).
Blend tally example
R3: ma.FY → m(+1, active), FY(+1) → 1 blend R7: CF.FC' → CF(+1), FC'(+1) → 1 blend (color-shading blend) R9: M.FC → M(+1), FC(+1) → 1 blend FM count, m count, FC/CF, FC', FY each get +1 where they appear. Blends:R numerator = 3 (three responses were blends)
Do not double-code a family. Coding both FC and CF for one determinant, or logging a blend twice, corrupts WSumC, eb, and es. When color vs shading intent is unclear, apply the step-down / "code Y when in doubt" rules from the coding guide.

Part VIIIForm Quality (FQ)

SymbolNameBasis
+Superior-OverelaboratedUnusually precise, enriched use of form (still fits)
oOrdinaryCommon, easily-seen form matching the area (in FQ table)
uUnusualLow-frequency but the contour is not violated; a defensible fit
−MinusForm is distorted / arbitrary; contours violated
noneNo formResponse has no form basis (e.g., pure C, pure Y, pure C')
Form Quality is looked up, not guessed. Whether a given object in a given area is o, u, or − is read from the Form Quality reference table — never decided from memory. This guide shows you the procedure; you read the actual grade from the table.

How FQ enters the Summary

Tally FQ+, FQo, FQu, FQ−, FQnone. These feed the mediation percentages (XA%, WDA%, X+%, X−%, Xu%) — see Part XXIII. The "form appropriate" set for XA% is +, o, u; the "distorted" set is −.

Difficult cases

  • Form clearly accurate → look up; usually o.
  • Form vague → the response may be DQv with FQ derived from the table for that vague class.
  • Form distorted → −.
  • Form not used (response rests on color/shading only) → none.
  • Multiple determinants → FQ reflects the form component; a formless blend member does not create form.
  • Uncertain between u and − → decide by whether the contour is violated (−) or merely uncommon (u), consulting the table.

Part XPopulars (P)

A Popular is a response that occurs with high frequency across records for a specific card and location. Each card has a defined set of Popular contents.

Look up the Popular list. Which answer counts as Popular on which card is fixed and must be checked against the Popular reference list — do not guess it from memory. This guide only shows you how to count the P responses once you have marked them.

Procedure

1
For each response, check the card + location + content against the Popular list.
2
If it matches, mark P in the code string.
3
Count the number of responses marked P → that count is P.
4
A single response earns at most one P even if it contains several contents.
Example
Responses marked P (after list check): R2, R5, R9, R14 P = 4

Part XIZ Scores — Zf, Zsum, Zest, Zd

The Z score rewards organising the blot: a response earns a Z value when the person pulls parts together in a meaningful way. A response qualifies for Z if it does any of these: a form-based DQ+; relates two or more touching areas; relates two or more separated areas; or uses the white space together with the blot.

TermMeaning
ZfZ frequency — number of responses that received a Z value
ZsumSum of the actual Z values assigned
ZestEstimated Zsum expected for that Zf, read from the Zest reference table
ZdZsum − Zest (efficiency of organisation)
Two reference tables are needed here. (1) The Z value table gives the exact Z number for each type of organising on each card — look it up, never invent it. (2) The Zest table gives the expected Zsum for each Zf — also looked up. Any Z numbers shown in this guide are examples only, marked "example."

Calculation procedure

1
Identify every response that qualifies for Z.
2
For each one, read its Z value from the Z value table.
3
Record each Z value.
4
Zf = count of Z-scored responses.
5
Zsum = add all the Z values.
6
Zest = read it from the Zest table for your Zf.
7
Zd = Zsum − Zest.
Zd
Zd = Zsum − Zest
Example (Z values & Zest shown as examples)
Z-scored responses & their table values (example): R1 = 1.0 R3 = 2.5 R6 = 3.0 R8 = 1.0 R11 = 2.5 R14 = 4.0 R17 = 2.0 Zf = 7 (seven responses scored Z) Zsum = 1.0+2.5+3.0+1.0+2.5+4.0+2.0 = 16.0 Zest = 20.0 (example table value for Zf = 7) Zd = Zsum − Zest = 16.0 − 20.0 = −4.0
Zd = −4.0 → underincorporation (hasty scanning). Positive Zd → overincorporation (overly careful).

Z-score difficult cases

  • No Z responses / Zf = 0 → Zsum = 0; Zd cannot be meaningfully computed (Zest is undefined for Zf = 0). Report Zf = 0 and withhold Zd.
  • Zsum very low / high → still valid; the value flows into Zd.
  • Zest cannot be read (Zf is below the smallest value on the table) → do not stretch or guess a figure.
  • Not sure a response earns Z → re-check the four ways to earn Z; if it qualifies in more than one way, use the single highest value that applies — do not add them together.

Part XIISpecial Scores

CodeNameCore idea
DVDeviant VerbalisationNeologism or redundancy
DRDeviant ResponseInappropriate phrase / circumstantial rambling
INCOMIncongruous CombinationImplausible single-object merge (e.g., a four-legged bird)
FABCOMFabulised CombinationImplausible relationship between objects

CONTAMContaminationTwo impressions fused into one impossible percept (most serious)

Each of the six above (the "Sum6" scores) is scored at Level 1 (mild) or Level 2 (severe) except ALOG and CONTAM. Other special scores that are tallied but not part of Sum6: AB (abstraction), AG (aggressive movement), COP (cooperative movement), MOR (morbid), PER (personal), PSV (perseveration), CP (color projection), and the human-representation scores GHR/PHR.

For each special score

1
Confirm what it is and its exact scoring criterion.
2
Confirm when it is scored (Level 1 vs Level 2 for the Sum6 set).
3
Tally its frequency.
4
Guard against false positives (colloquialisms are not DV; a plausible relationship is not FABCOM).
5
Enter frequencies in the Summary.
6
Compute Sum6 and WSum6 (weighted).

Sum6 and WSum6

Sum6 (raw)
Sum6 = DV + INCOM + DR + FABCOM + ALOG + CONTAM (all levels)
WSum6 (weighted)
WSum6 = Σ (each critical special score × its weight)
Each of the six scores has a fixed weight. The Comprehensive System gives DV, INCOM, DR, FABCOM, ALOG, and CONTAM a set weight (a Level 2 score weighs more than the same score at Level 1, and CONTAM weighs the most). These weights are read from the reference table, not invented. To get WSum6 you multiply each score by its weight and add the results.
WSum6 — worked example
Say the record contains: 1 × DV (Level 1) 1 × INCOM (Level 1) 1 × FABCOM (Level 1) Step 1 — raw Sum6 = 1 + 1 + 1 = 3 (Lv2 = 0) Step 2 — multiply each by its table weight, then add: WSum6 = (1 × weight of DV) + (1 × weight of INCOM) + (1 × weight of FABCOM) The key idea: WSum6 grows FASTER than the raw Sum6, because the more serious scores carry heavier weights. So a record with the same NUMBER of scores can still have very different WSum6 values depending on which scores they are and whether they are Level 1 or 2.

Special-score difficult cases

  • One DV → Sum6 += 1; WSum6 += w(DV, level).
  • Multiple DV → each counts; sum the weights.
  • DV + DR in one response → both are scored (a response may carry more than one special score).
  • Level 2 → uses the heavier weight; also tally Lv2.
  • CONTAM → highest weight; rare and serious.
  • Ambiguous → do not guess; re-read the verbalisation against the criterion (Part XXXII).

Part XIVLambda (L)

Lambda
L = F ÷ (R − F)

F = number of pure Form responses  ·  R = total responses  ·  R − F = responses that used any determinant other than pure F.

Lambda indexes the tendency to simplify — to deal with the blot economically using shape alone. High Lambda (> 0.99) marks an avoidant style.

Example 1 — ordinary
R = 20 F = 5 R − F = 20 − 5 = 15 L = F ÷ (R − F) = 5 ÷ 15 = 0.33
Lambda = 0.33
Example 2 — no pure F
R = 20 F = 0 R − F = 20 − 0 = 20 L = 0 ÷ 20 = 0
Lambda = 0. Every response carried a non-form determinant; no simplifying/avoidant tendency by this index. Interpret with the rest of the record.
What if — Example 3: ALL responses are pure F (mandatory case)
R = 17 F = 17 R − F = 17 − 17 = 0 L = 17 ÷ 0 → DIVISION BY ZERO → mathematically UNDEFINED

Mathematical result: undefined (denominator is zero).

What to actually do: do not quietly turn this into an ordinary finite Lambda. A record made only of pure-F responses is an extreme, very constricted one. Report it as an extreme high-Lambda case and treat the record as avoidant and barely interpretable (see validity, Part XXVIII). State the boundary honestly instead of writing a made-up number.

Distinguish
MATHEMATICAL RESULT (undefined) ≠ CLINICAL/REPORTING CONVENTION (extreme high-Lambda flag + validity caution).
Example 4 — near-all pure F
R = 10 F = 9 R − F = 10 − 9 = 1 L = 9 ÷ 1 = 9.0
Lambda = 9.0 — an extremely high value. Caution: only one response used anything beyond form; the record is markedly constricted/avoidant and its interpretability is limited.

Part XVExperience Balance (EB)

EB
EB = M : WSumC

M = number of human-movement responses. WSumC = 0.5·FC + 1.0·CF + 1.5·C.

EB contrasts ideational (M) with affective (weighted color) coping. Style is read from which side dominates — but only when the record is rich enough (see edge cases).

EB worked example
Given: M = 4, FC = 2, CF = 3, C = 1 WSumC = 0.5·2 + 1.0·3 + 1.5·1 = 1.0 + 3.0 + 1.5 = 5.5 EB = M : WSumC = 4 : 5.5
EB = 4 : 5.5 → color side slightly dominant → tends extratensive (confirm validity + EBPer before labelling).

EBPer (pervasiveness)

EBPer
EBPer = (larger EB side) ÷ (smaller EB side)

Computed only when a valid, clearly one-sided EB exists. For example, an EB of 2 : 10 gives EBPer = 10 ÷ 2 = 5.0 — a strong, pervasive lean toward the affect side.

Do not label an EB style when EA is below 4.0. When EA is under 4.0 there are simply too few responses on each side to trust the balance. In that case you do not call the person introversive or extratensive. If Lambda is also high (≥ 1.0), the better description is an avoidant style. Example: an EB of 2 : 0 with EA of only 2.0 is not read as introversive — EA is too low for the style to mean anything.

Part XVIEA — Experience Actual

EA
EA = M + WSumC

EA sums the two EB sides — the total of accessible, organised resources.

Five examples

Part XXAdjusted D (AdjD)

AdjD asks: what is control like once situational stress is removed? It re-runs the D calculation using Adjusted es (Adj es) instead of es.

AdjD (procedure)
Adj es = es − (the extra, passing amount of m and Y) AdjD = D-table conversion of (EA − Adj es)

The adjustment takes out the passing load carried by inanimate movement (m) and diffuse shading (Y) above a set baseline, leaving the steady, trait-level picture.

Example — situational strain present
es = 10, Adj es = 7 (the extra m and Y are taken out) EA = 12 EA − Adj es = 12 − 7 = +5 → positive band AdjD = +1 (while D = 0) What this means: the baseline (trait) control is above average (AdjD = +1), but right now it is pulled down to average (D = 0) by some passing, situational pressure.
Example — no situational component
es = 9, Adj es = 8, EA = 2.0 D = −2 and AdjD = −2 What this means: because D and AdjD are the SAME, the overload is long-standing, not just a passing stress. Removing the small situational part does not change the picture.
Only remove the extra m and Y, not all of them. The adjustment takes out the small, passing amount of inanimate movement (m) and diffuse shading (Y) above a set baseline — never every m and Y. Use the stated rule for how much to remove.

Part XXXIEdge-Case "What If?" Index ★ Second most important

For each case we cover: (1) the maths, (2) whether it is defined, (3) what to write down, (4) whether to report a value at all, (5) any special rule for that boundary, (6) whether to hold back interpretation, (7) what to double-check.

What if the NUMERATOR is zero?
Maths: 0 ÷ d = 0 (for d ≠ 0). Defined. Enter 0. Report it. No special convention. Interpret normally (a genuine zero, e.g., X−% = 0 means no minus responses). Re-check the tally that produced the zero.
What if the DENOMINATOR is zero?
Maths: n ÷ 0 = undefined. Not defined. Do not enter a number. Report the boundary ("undefined / not computable"). Some ratios are written as "n:0" (a ratio, not a division — that is fine, e.g., FC:CF+C = 3:0). Withhold any interpretation that needs the quotient. Re-check whether the record is degenerate (e.g., no I–VII responses for Afr).
What if BOTH are zero?
Maths: 0 ÷ 0 = undefined; as a ratio, 0:0. Enter the ratio as 0:0 where a ratio is expected (e.g., FC:CF+C = 0:0). No quotient. Withhold modulation/quotient interpretation. Re-check that both underlying counts really are zero.
What if R is VERY LOW?
All percentages that divide by R become shaky, and some constellations cannot be scored. Compute what you can, but check R against the set minimum (Part XXVIII) and most likely hold back on cluster interpretation.
What if R is VERY HIGH?
Frequencies inflate; percentages may compress. Values are defined; interpret cautiously with the over-productivity caveat.
What if there are NO COLOR responses?
WSumC = 0; FC:CF+C = 0:0; EB affect side = 0; Afr may still compute from card counts. Report; the affect side of EB is empty and EB style may be invalid if EA < 4.
What if there are NO MOVEMENT responses?
M = 0, FM = 0, m = 0 → EB left side 0, eb left side 0. Defined (zeros). Report; note absence of ideational/kinesthetic activity.
What if M = 0?
EB = 0:WSumC; Ma:Mp = 0:0; M− = 0. All defined as zeros. Report; EB weighted entirely to affect side (if valid).
What if FM = 0 / m = 0?
eb left side loses that component. Defined. Report zeros; recompute es accordingly.
What if F = 0?
Lambda = 0 ÷ R = 0. Defined. Enter 0. No avoidant signal from Lambda. Re-check that truly no response was pure F.
What if ALL responses are pure F?
R − F = 0 → Lambda = R ÷ 0 = undefined. Do not fabricate a finite value; report the extreme high-Lambda boundary and treat as a constricted/avoidant, minimally interpretable record (Part XIV, Example 3). Re-check FQ-vs-F confusion.
What if the LAMBDA denominator = 0?
Same as the all-pure-F case above. It is undefined; report it as the extreme high-Lambda boundary, not a made-up number.
What if Zf = 0?
No organisational activity. Zsum = 0; Zest is undefined for Zf = 0; Zd cannot be computed. Report Zf = 0, withhold Zd.
What if Zsum = 0 (but Zf > 0)?
Unusual — check for a tallying error, since a Z-scored response carries a positive value. Re-verify the Z values.
What if there are NO special scores / Sum6 = 0 / WSum6 = 0?
Enter 0 for both Sum6 and WSum6. This is a real, defined value. Report it; it means no formal thought-disorder markers are present.
What if FC = 0 / CF+C = 0 / both = 0?
FC:CF+C becomes 0:(CF+C), FC:0, or 0:0. Ratios (not divisions) are fine to report; when both are 0 withhold modulation interpretation.
What if H = 0 / (H) = 0?
H:(H)+Hd+(Hd) = 0:(sum) or (H)=0 contributes nothing to the right side. Defined. Report; no Pure H flags reliance on partial/imaginary human conceptions.
What if MOR = 0 / FD = 0 / An+Xy = 0 / 3r+(2) = 0?
Each is a genuine count of zero — enter 0, report, interpret as absence. Not undefined.
What if a required variable CANNOT be calculated / data are MISSING?
Document the gap. Any ratio or constellation depending on the missing variable is withheld (not guessed). Re-check the coding sheet and inquiry notes; if truly missing, flag it in the report.
Golden rule for all edge cases
Always distinguish the mathematical result (defined / zero / undefined) from the reporting convention (what number, ratio, or flag actually goes on the Summary). When in doubt, report the boundary honestly and withhold interpretation rather than inventing a value.
